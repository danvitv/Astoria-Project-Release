# Astoria Project — releases and curated cards

Public downloads and the **Our Picks** catalog for Astoria Project.

[Source code](https://github.com/danvitv/Astoria-Project) · [GitHub: danvitv](https://github.com/danvitv)

The catalog is served from [`picks/`](picks/index.json). Releases will appear on the [Releases page](https://github.com/danvitv/Astoria-Project-Release/releases) when builds are ready.

Source code and development are public under AGPL-3.0 in [`danvitv/Astoria-Project`](https://github.com/danvitv/Astoria-Project). This repository contains the curated catalog and future release files, not a second copy of the app source.
