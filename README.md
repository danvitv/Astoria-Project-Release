# Astoria Project — releases and curated cards

Public downloads and the **Our Picks** catalog for Astoria Project.

[GitHub: danvitv](https://github.com/danvitv)

The catalog is served from [`picks/`](picks/index.json). Releases will appear on the [Releases page](https://github.com/danvitv/Astoria-Project-Release/releases) when builds are ready.

Source development takes place in a separate private repository. This repository contains the public catalog and release files, not the app source.
